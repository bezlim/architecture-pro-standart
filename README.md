# Архитектура ИТ-систем банка «Стандарт»

## О компании

«Стандарт» — небольшой банк с сайтом и интернет-банком. Основная категория клиентов — люди старшего возраста, предпочитающие офлайн-обслуживание.

### Текущее состояние

- **Сайт**: показывает только маркетинговую информацию
- **Интернет-банк**: проведение платежей и открытие текущих счетов (дебетовых карт)
- **Основной канал обслуживания**: отделения банка (50 отделений, 500 сотрудников)

## Проблемы бизнеса

- Клиенты редко пользуются онлайн-каналами
- Сайт имеет ограниченный функционал
- Необходимо привлечь более молодую аудиторию
- Требуется цифровая трансформация

## Планы развития

### 1. Интернет-банк — депозиты и накопительные счета

**Промежуточное состояние (6 месяцев)**
- Клиент может открыть депозит или накопительный счёт в интернет-банке
- Обработка заявок бэк-офисом по старому процессу (MVP)

**Финальное состояние (1 год)**
- Полностью автоматическое открытие депозитов и накопительных счетов
- Бэк-офис не участвует в процессе
- В отделениях задействованы только сотрудники фронт-офиса

### 2. Интернет-банк — кредитные заявки

- Подача кредитной заявки из интернет-банка
- Клиент сразу видит возможность получения кредита
- Решение в течение одного дня (предодобренные предложения)

### 3. Сайт — заявки на депозиты и кредиты

- Подача заявки на депозит через сайт
- Менеджер кол-центра связывается с клиентом
- Подача заявки на кредит с сайта (данные только из БКИ)
