# Банк «Стандарт» — Кредитный процесс (As-Is)

## Обзор

Процесс рассмотрения заявки на кредит. Операции выполняется офлайн в отделениях банка. Онлайн-каналы не используются. Среднее время прохождения процесса — 3 дня.

## Участники

- **Клиент:** Инициатор процесса, заёмщик
- **Менеджер отделения:** Приём заявки, первичная проверка, оформление документов
- **Сотрудник бэк-офиса:** Ручное рассмотрение заявок, финальное утверждение
- **IT-системы:** Автоматизированная обработка данных и маршрутизация

## ИТ-системы

- **АБС (Oracle/Delphi):** Ядро учёта, хранение анкет, выдача средств
- **Кредитный конвейер (Camunda):** Оркестрация процесса, BPMN-схемы
- **Система скоринга (Python/Flask):** ML-расчёт риска и рейтинга
- **БКИ (Внешний API):** Источник кредитной истории
---

## Пошаговое описание процесса

### Шаг 1. Подача заявки

Клиент обращается в отделение. Менеджер регистрирует клиента в **АБС** (desktop-клиент на Delphi).

### Шаг 2. Предварительная проверка

**Кредитный конвейер** автоматически выгружает данные заявки из **АБС** через интеграцию раз в день. 

### Шаг 3. Скоринг и оценка риска

**Кредитный конвейер** отправляет запрос в **Систему скоринга** через REST API. Скоринг-сервис на Python запрашивает кредитную историю клиента во внешнем **БКИ** (через REST API) и данные из АБС раз в день. На основе модели машинного обучения рассчитывается рекомендуемая процентная ставка. Результат возвращается в конвейер.

### Шаг 4. Принятие решения

- **Ручное рассмотрение:** Заявка попадает в очередь сотруднику бэк-офиса. Заявки переходят в финальный статус и потом раз в сутки эта информация передается в **АБС** через интеграцию, где проводятся платежи для зачисления кредитных средств на счет клиента.
